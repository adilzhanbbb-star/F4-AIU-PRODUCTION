        HTTP-запросы
          HTTP-методы и коды ответов

          Методы: GET — получить данные; POST — создать; PUT — полностью заменить; PATCH — частично изменить; DELETE — удалить.

          Классы: 1xx — информационные; 2xx — успех; 3xx — перенаправление; 4xx — ошибка клиента; 5xx — ошибка сервера.

          2xx: 200 OK — успешно; 201 Created — создано; 204 No Content — успешно без тела ответа.

          3xx: 301 Moved Permanently — постоянный перенос; 302 Found — временное перенаправление; 304 Not Modified — не изменено.

          4xx: 400 Bad Request — неверный запрос; 401 Unauthorized — требуется авторизация; 403 Forbidden — доступ запрещён; 404 Not Found — не найдено; 405 Method Not Allowed — метод запрещён; 429 Too Many Requests — слишком много запросов.

          5xx: 500 Internal Server Error — ошибка сервера; 502 Bad Gateway — ошибка взаимодействия серверов; 503 Service Unavailable — сервер временно недоступен.
