# F4-AIU-PRODUCTION

## Тапсырмалар тізімі

Жобаның басты бетін ашу үшін `index.html` файлын браузерде ашыңыз.

- **Жоспар** қойындысында API сілтемесін енгізіп немесе дайын мысалды таңдап, тапсырмалар тізімін жүктеуге болады. Бұл қойындыдағы өзгерістер браузерде сақталады және сыртқы серверге жіберілмейді.
- **API** қойындысы DummyJSON қолданушыларын және тапсырмаларын `fetch()` арқылы жүктейді. Әр тапсырманың астындағы шағын карточкада тапсырмаға тиесілі қолданушының ID-і мен аты көрсетіледі; карточканы басқанда профиль ашылады. Ағымдағы қолданушыны таңдау мен тапсырма әрекеттерінің тарихы да осы API ID-леріне байланысады. Қосу, өңдеу, күйін өзгерту және өшіру әрекеттері REST API сұрауларын жібереді. DummyJSON сынақ API-і болғандықтан, қосылған тапсырмалар жаңартқаннан кейін жоғалуы мүмкін.

Мысал API-лер: [DummyJSON Todos](https://dummyjson.com/todos), [JSONPlaceholder Todos](https://jsonplaceholder.typicode.com/todos).
