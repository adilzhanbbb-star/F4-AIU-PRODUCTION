# F4-AIU-PRODUCTION

## Тапсырмалар тізімі

Жобаның басты бетін ашу үшін `index.html` файлын браузерде ашыңыз. Сыртқы API-ден тапсырма жүктеу үшін сілтемені енгізіңіз немесе дайын мысалдардың бірін таңдаңыз. Қосу, өңдеу, өшіру және орындалды деп белгілеу өзгерістері әр API тізімі үшін осы браузерде сақталады; сыртқы API серверіне жіберілмейді.

Мысал API-лер: [DummyJSON Todos](https://dummyjson.com/todos?limit=0), [JSONPlaceholder Todos](https://jsonplaceholder.typicode.com/todos).
